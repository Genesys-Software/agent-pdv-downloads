# Agent PDV - Downloads

Canal de distribuicao do agente PDV. Os instaladores e manifestos assinados serao publicados em Releases. O codigo-fonte permanece em repositorio privado.

## Atualizacoes

As estacoes validam a assinatura do manifesto e o SHA-256 do executavel antes de aplicar uma atualizacao do Windows. A primeira versao com suporte a este canal precisa ser instalada manualmente.
